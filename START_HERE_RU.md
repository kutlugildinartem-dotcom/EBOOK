# Leaf: управление без ChatGPT

Это полный исходный код Leaf, а не только HTML-страница. Книг пользователя, паролей и ключей в комплекте нет.

## Что уже работает

Основной сайт: https://leaf-reader-michael.windytitan128.chatgpt.site/ . Он продолжает работать независимо от открытого чата. Код этого комплекта можно разместить в своём репозитории и собрать на своём компьютере или в GitHub Actions.

## Свой репозиторий

1. Репозиторий проекта: https://github.com/kutlugildinartem-dotcom/EBOOK .
2. Для бесплатного GitHub Pages потребуется публичный репозиторий. Для Pages из приватного репозитория нужен подходящий платный план GitHub. Публичный репозиторий делает исходники видимыми всем.
3. Загрузите содержимое этой папки в ветку `main`, сохраняя вложенные каталоги, включая `.github/workflows/pages.yml`.
4. В Settings → Pages → Build and deployment выберите Source → GitHub Actions.
5. В Actions откройте Publish Leaf и запустите Run workflow, если публикация не началась после загрузки файлов.
6. После успешной публикации адрес появится в Settings → Pages и в результате задания deploy. Не путайте его с адресом сайта ChatGPT Sites: это отдельное размещение.

## Редактирование в VS Code

Установите Node.js 24, Python 3 и Git (команда `python3` должна быть доступна в терминале). Клонируйте свой репозиторий через VS Code: Clone Git Repository. В терминале проекта:

```sh
corepack enable
corepack prepare pnpm@11.25.0 --activate
pnpm install --frozen-lockfile
pnpm prepare:assets
pnpm dev
```

Для самостоятельной статической сборки:

```sh
pnpm build:static
```

Результат — `dist-static/index.html`. Его можно разместить на любом статическом хостинге. Для локальной проверки запустите `python -m http.server 8080 --directory dist-static` и откройте http://localhost:8080 .

## Как выпускать изменения

Редактируйте файлы в `app/`, сохраните изменения через Source Control → Commit, затем Sync Changes. После отправки в `main` GitHub Actions проверит и пересоберёт сайт. После успешного задания deploy обновите страницу на телефоне. Если сборка красная, откройте журнал Actions: предыдущая опубликованная версия останется доступной.

Основные файлы: `app/page.tsx` — интерфейс; `app/globals.css` — оформление; `app/translation-service.ts` и `translation/worker.ts` — перевод; `app/import-book.ts` — импорт.

## Особенности отдельного размещения

GitHub Pages размещает статические файлы и не запускает серверный `/api/translate`. Поэтому в статической сборке доступен перевод на устройстве; настройка Google скрыта/отключена. Первый запуск локального переводчика требует сети для загрузки модели примерно на 100 МБ. Качество сложной прозы ограничено локальной моделью.

Книги и позиция чтения сохраняются в браузере каждого устройства. Переход на другой адрес сайта или другой телефон не переносит книги автоматически. На телефоне книгу нужно добавить заново. Перед сменой адреса сохраните исходные файлы книг.

Секреты для GitHub Pages не требуются. Ничьи пароли, токены или API-ключи не добавляйте в репозиторий.

Справка GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

Словарь пересобирается из включённого `public/dictionary/source.tar.xz`, PDF-воркер и среда перевода копируются из установленных npm-пакетов. Это сохраняет весь исходный материал, не дублируя десятки мегабайт сборочных файлов в Git.
