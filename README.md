# Leaf — читать и понимать

Читалка английских книг с русским подстрочным переводом и объяснением распознанных грамматических конструкций. Словарь и правила работают на устройстве. Есть два режима связного перевода: Google через сервер и перевод на устройстве без дневной квоты.

## Возможности

- Импорт EPUB, PDF с текстовым слоем, DOCX и TXT; обложки и метаданные EPUB.
- Библиотека с раскрывающейся объёмной обложкой: текст и изображение находятся в одной плоскости, верхних и нижних выступающих граней нет. Кнопки «Читать» и «Изменить».
- Редактирование названия, автора и обложки.
- Страницы по размеру экрана, абзацы, заголовки глав, оглавление и обзор миниатюр.
- Всплывающая карточка перевода: контекст, употребление, варианты, произношение и правила.
- Слово или выделение переводятся в карточке. Кнопка справа сверху заменяет всю страницу русским переводом; повторное нажатие возвращает оригинал. Абзацы и заголовки сохраняются.
- Быстрые вкладки всех значений словаря и правил текущего предложения; английские слова внутри карточки открывают отдельный разбор с возвратом.
- Ручное выделение движением; неподвижное удержание 1 секунду выделяет предложение, 2 секунды — абзац.
- Тема, размер и пять шрифтов, клавиатура, свайпы и обзор страниц сведением пальцев.
- Книги, позиция чтения, настройки и выделения сохраняются в браузере.

Кнопки громкости и датчик наклона работают, только если браузер и устройство передают необходимые события. Сканы PDF и DRM не поддерживаются. Словарный выбор значения и эвристический разбор грамматики могут ошибаться; полного покрытия всех слов и правил нет. Онлайн-перевод тоже не гарантирует безошибочность.

## Разработка

Нужны Node.js >=22.13 и pnpm версии из package.json.

```sh
pnpm install
pnpm dev
```

Проверки и сборка:

```sh
node tests/language-engine.test.mjs
node tests/translation-selection.test.mjs
pnpm exec tsc --noEmit
node scripts/build-translation-worker.mjs
pnpm build
```

Технические сведения о среде, развёртывании и конфигурации — в [docs/hosting-development.md](docs/hosting-development.md).

## Перевод и ограничения

По умолчанию включён режим на устройстве: суточной квоты приложения нет. Дополнительный режим Google вызывает POST `/api/translate`. Сервер обращается к публичному веб-эндпоинту Google; это не официальный Cloud Translation API и не гарантированный коммерческий сервис. В проверке размещённого сервера 31.10.2026 Google вернул HTTP 429. Этот режим нельзя считать надёжно работающим до подключения официального Cloud Translation API с учётными данными. Google может изменить доступность или отклонить запросы. Такие ошибки отображаются явно; приложение не пытается обходить ограничения сервиса. Отправляются выбранные фрагменты; вся библиотека не загружается. Ключи и платные аккаунты не используются.

В приложении нет дневного лимита и ограничения выделения в 5000 символов. Большие тексты делятся на запросы без потери конца, сохраняются абзацы. Перевод кэшируется на устройстве отдельно для каждого движка.

Режим «На устройстве» сначала использует Chrome Translator API, если он доступен для английского и русского. Иначе используется Helsinki-NLP OPUS-MT en→ru в версии Xenova/Transformers.js 3.8.1, q8, WebAssembly, отдельный Worker. Первая загрузка весов и WASM — около 100 МБ. Модель хранится в отдельной IndexedDB; при нехватке места кэширование может не сохраниться. Суточной квоты у локального режима нет, но качество ниже облачных сервисов на сложной прозе и идиомах, а скорость и доступность зависят от устройства. Перевод не заменяет профессиональную редактуру.

Локальный HTML использует режим на устройстве; Google через сервер доступен в размещённой версии. Для первого запуска локальной модели нужен интернет. При ошибке сохранены английский оригинал и ссылка на веб-интерфейс Google Переводчика.

Проверены: перевод всей страницы на месте с возвратом оригинала, отсутствие подстрочных вставок при нажатии слова, ручное выделение и удержания 1/2 секунды. Тесты покрывают разбиение UTF-8, сохранение длинных текстов, кэш, разделение движков, отмену запросов, обработку ошибок и повтор.

## Уточнения перевода страниц

Предложения, пересекающие границу экрана, передаются переводчику целиком. На соседних страницах граничное предложение может повторяться: это сохраняет смысл вместо перевода двух обрывков. Короткие предложения объединяются в контекстные группы, ограниченные размером входа локальной модели; общий объём текста не обрезается. Переведённые абзацы появляются по мере готовности, не ожидая обработки всей страницы. Старый кэш перевода автоматически отделён от обновлённого.

Убраны искусственные ограничения импорта на 25 МБ, 100 МБ распакованного EPUB и 3 миллиона символов. Возможность обработки большой книги зависит от свободной памяти браузера и места на устройстве.
