# Android APK Leaf

APK содержит собранное приложение, словарь, PDF-воркер и среду WASM. Сам сайт для чтения не нужен. Для первого запуска нейронного перевода нужен интернет для скачивания модели; книги и позиция чтения хранятся внутри приложения на устройстве.

## Самостоятельная сборка

Workflow: `.github/workflows/android.yml`, название в Actions — **Build Android APK**. Он запускается при изменении исходников или вручную через Run workflow и собирает APK из той же версии кода.

Исходный Android-проект: `android/`. Идентификатор приложения: `app.leaf.reader`. Минимум Android 8.0 (API 26); нужен обновлённый Android System WebView. Книги выбираются стандартным системным окном. Разрешение на доступ ко всему хранилищу не требуется.

Результат GitHub Actions — архив **Leaf-Android-build**, содержащий `Leaf-unsigned.apk`, `apksigner.jar`, сведения о версии и контрольную сумму. APK намеренно собирается без секретного ключа: приватная подпись не хранится в публичном репозитории.

Для подписи нужен приватный архив `Leaf_android_signing_backup.zip`, переданный владельцу вместе с первой сборкой. Он содержит keystore, пароль и инструкцию. Не публикуйте этот архив в GitHub. Для будущих обновлений используйте тот же ключ и увеличивайте `versionCode` в `android/app/build.gradle`.

После извлечения файлов сборки и архива подписи в одну папку:

```sh
java -jar apksigner.jar sign --ks leaf-release.p12 --ks-key-alias leaf --ks-pass file:keystore-password.txt --key-pass file:keystore-password.txt --out Leaf.apk Leaf-unsigned.apk
java -jar apksigner.jar verify --verbose Leaf.apk
```

Для этого достаточно установленной Java 17. Android Studio/SDK локально не требуются, если неподписанный APK уже собрал GitHub Actions.

Книги браузерной версии и APK хранятся отдельно. После установки APK исходные EPUB/PDF/DOCX/TXT надо добавить в его библиотеку. Удаление приложения удаляет его локальную библиотеку; обновление APK с тем же ключом и идентификатором сохраняет данные.
