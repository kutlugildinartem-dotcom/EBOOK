# Обновление режима чтения и импорта

## Экран книги

При чтении убраны верхняя и нижняя панели, название книги, счётчик, прогресс и постоянные кнопки. В обычном состоянии остаётся только текст книги. Карточка перевода появляется по явному нажатию или выделению.

| Действие | Жест |
| --- | --- |
| Следующая / предыдущая страница | Свайп влево / вправо |
| Меню чтения | Свайп вверх |
| Обзор страниц и оглавление | Развести два пальца; сведение тоже поддержано |
| Одно слово | Короткое нажатие |
| Несколько слов | Удержать около 0,35 секунды, затем вести пальцем |
| Предложение | Удержать около 1 секунды без движения |
| Абзац | Удержать около 2 секунд без движения |

Меню содержит перевод страницы, правила текста, переход по страницам, выбор книги, настройки, полный экран и выход. В обзоре страниц также есть доступ к меню, правилам и выходу. На клавиатуре: M — меню, O — обзор, стрелки — страницы, Escape — закрыть окно или выйти.

На странице, которая действительно длиннее экрана (например, русский перевод), движение в середине текста прокручивает его. Для открытия меню на такой странице свайп вверх нужно начинать у нижнего края, в пределах последних 100 пикселей. Это позволяет читать конец длинного перевода, сохраняя доступ к настройкам.

## Почему свайпы раньше выделяли слова

Прежний обработчик сразу создавал выделение при касании слова и переводил любое движение больше 6 пикселей в выделение нескольких слов. Удержание для этого не требовалось. При отпускании пальца выделение имело приоритет перед перелистыванием и меню.

Теперь жест получает одно намерение. Если движение началось до выдержки удержания, это навигация; остановка посреди свайпа уже не превращает его в выделение. Выделение с движением включается только после удержания. Небольшое дрожание пальца допускается. Таймеры отменяются при навигации, отмене указателя и переключении приложения. Второй палец отменяет однопальцевое выделение и начинает жест обзора. Дублирующие обработчики Touch/Pointer заменены одним обработчиком Pointer Events. Браузерное выделение и перехват вертикального свайпа на поверхности чтения отключены.

## Импорт книг

- **EPUB:** порядок глав берётся из spine; пропускаются элементы навигации и элементы вне основного чтения (`linear=no`); сохраняются автор, название и явные заголовки. Обычный абзац `The Picture of Dorian Gray` больше не становится заголовком только из-за заглавных букв.
- **DOCX:** сохраняются заголовки из структуры документа. Проверен настоящий ZIP-контейнер DOCX со стилем Heading 1 и обычными абзацами.
- **TXT:** обычные строки с именами и заглавными буквами не объявляются заголовками. Учитываются явные маркеры глав, римские номера и короткий подзаголовок непосредственно после маркера главы. Проверены UTF-8, UTF-16 LE/BE, UTF-16 без BOM и текст Windows-1252. Поддержан резервный разбор Windows-1251.
- **PDF:** строки восстанавливаются по координатам; размер основного шрифта оценивается по всей книге. Повторяющиеся колонтитулы в полях и номера страниц исключаются. Строки с именами не считаются заголовками из-за регистра. Сохраняется продолжение абзаца между страницами. Проверены переставленные текстовые элементы, повторяющийся заголовок `The Picture of Dorian Gray` и номер страницы.
- Исправлена устаревшая подпись «до 25 МБ»: действующего искусственного ограничения такого размера нет.

## Уже добавленные книги

Старая классификация ложных заголовков корректируется при загрузке библиотеки. Сам текст не пересобирается и не обрезается: позиции чтения и смещения заметок остаются прежними. Настоящие явные заголовки новых импортов защищены версией парсера.

Если старая версия уже включила колонтитулы PDF в текст или неправильно склеила строки, полное повторное чтение исходного файла требует повторного импорта. Исходный файл в библиотеке приложения не хранится. Автоматическое исправление старых заголовков не удаляет эти строки, чтобы не нарушить заметки и позицию чтения.

## Проверки

- 1000 автоматических трасс свайпа, начинающихся на слове, включая остановку после начала движения: ни один не переключился в выделение.
- Отдельные тесты короткого нажатия, удержания с движением, удержания на месте, свайпа вверх, дрожания пальца, прокрутки и обоих направлений щипка.
- Проверка структуры тестовых EPUB и DOCX, порядка глав, метаданных, вложенных HTML-блоков, скрытых разделов, TXT-кодировок и PDF-колонтитулов.
- Проверка миграции старых заголовков без изменения текста и смещений.
- Существующие проверки словаря, грамматики, пагинации, длинного перевода и сохранения текста.
- Проверка типов TypeScript и сборка статического сайта.
- В браузере: чистый экран чтения, слово по короткому нажатию, предложение по удержанию 1 секунду, абзац по удержанию 2 секунды, выделение нескольких слов после удержания и движения, открытие меню свайпом вверх.

Тесты добавлены в GitHub Actions и выполняются перед публикацией.

## Границы проверки

Использованы тестовые фрагменты и контейнеры с названием The Picture of Dorian Gray, а не исходный файл с вашего телефона: он недоступен из этой среды. PDF без текстового слоя требует OCR. Сложные многоколоночные PDF могут потребовать отдельного разбора. Физический мультитач конкретного телефона не эмулировался: логика щипка проверена автоматическими тестами; остальные перечисленные взаимодействия проверены в браузере.
